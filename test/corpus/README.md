# Real-World Corpus (Layer C)

**Status: deferred (Phase 5).** This directory is reserved for workflows
collected from real public repositories.

Its purpose is **usefulness**, not correctness: _does CIProof find useful,
defensible issues on real workflows?_ Correctness is measured separately by the
unit tests (Layer A) and the compatibility suite (Layer B, see
`test/compatibility/`).

Nothing here runs in Phase 0. When populated, corpus workflows are parsed and
analyzed read-only; no workflow is ever executed.
